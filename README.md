# Source Weapons CS:S

The "Source Weapons" treatment to Counter-Strike: Source, and yet another CS:S weapon pack for Garry's Mod.

The weapons will be implemented in three passes:

1. Start with the 2007 implementation
2. Add in [2017](https://github.com/nillerusr/source-engine) changes
3. Add in [CS:S Enhanced](https://github.com/XutaxKamay/css_enhanced) changes (New weapons like the M82A1 will be their own pack)
